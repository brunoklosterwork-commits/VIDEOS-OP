# VIDEOS OP

Videos verticales (Reels / TikTok) con motion graphics para **OP Sistemas** — puertas placa y aberturas, San Lorenzo, Santa Fe ([opsistemas.co](https://www.opsistemas.co/) · [@opsistemas.ar](https://www.instagram.com/opsistemas.ar/)).

Identidad visual propia, independiente de Lo Habías Oído. Estado: **definiendo estilo**.

## Estructura (prevista)

| Carpeta | Contenido |
|---|---|
| `docs/` | Biblia de estilo, fórmula de guion, proceso técnico. |
| `estilo/` | Pruebas de dirección de arte (A/B/C) y el estilo elegido. |
| `motor/` | Código de animación y render. |
| `marca/` | Logo, colores, fotos de producto y obras. |
| `videos/` | Cada video: guion, voz, escenas y mp4. |
| `publicados/` | mp4 finales que Metricool toma por link. |

## Flujo

1. Claude escribe el guion de voz en off.
2. Bruno graba el audio y lo pasa.
3. Claude sincroniza, anima y renderiza el mp4.
4. Se sube a `publicados/` y se programa en Metricool.
